This is my personal portfolio website built using HTML, CSS, and external libraries like Google Fonts and Boxicons. It showcases my skills, projects, and provides a way to download my resume or contact me.


# Sections:

Home – Introduction and resume download

About Me – Background, technical stack, and profile picture

Skills – Programming and frontend development proficiencies

Projects – Highlighted work with GitHub link

Contact – Basic form to get in touch<br>



# Follow these steps to run the portfolio locally:</b>

1. <b>Clone the repository</b><br>

   git clone https://github.com/anuhegde07/Portfolio-Anusha-.git<br>
   
   cd Portfolio-Anusha-
   
2. <b>Ensure the following files exist in the root directory:</b>

   home.html

   index.css

   profile.png

   Resume.pdf

3. <b>Open home.html in your browser</b><br>

   You can simply double-click it or use Live Server (VS Code extension)<br>
   
   <b>If you have Live Server extension in VS Code:</b><br>
   
      Right-click home.html → "Open with Live Server"
